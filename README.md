# 맵툴 로그 정리기

MapTool 채팅 로그(HTML · 텍스트)를 읽기 좋은 세션 로그로 정리하는 한 장짜리 웹 페이지. 브라우저 안에서만 돌고, 로그·이미지는 그 브라우저(IndexedDB)에 남는다.

- 로그 파일 여러 개를 이어 보기 · 편집 · 모두 바꾸기
- 캠페인 파일(.cmpgn)·에셋 폴더로 토큰 이미지 자동 연결, BGM 파일 연결
- 표시 옵션(잡담 · 귓속말 · 주사위 식 · 시간 · 연속 발언 묶기 · 시스템), HTML/텍스트 내보내기

## 오레마스 연동
「오레마스 방 불러오기」 칸에 방 링크(`…/oremas/#r=방ID`)나 방 ID 를 넣으면 그 방의 로그를 읽어 온다.
- 대사 · *지문* · 주사위 · 배틀 카드(지령 · 고유 · 포텐셜 … 효과 본문 포함) · 시스템 줄을 옮긴다. 휴대폰 문자는 고르면 넣는다. 귓속말은 서버가 공개하지 않아 빠진다.
- 화자 초상은 방의 로스터(트레이너 · 포켓몬) · 관계도 · 스탠딩 그림에서 가져와 토큰 이미지로 잇는다.
- 오레마스의 「💾 로그 → 정리기에서 열기」는 `?oremas=방ID` 로 이 페이지를 열어 바로 불러온다.
- **오레마스에서 내보낸 파일**도 「로그 파일 추가」 · 끌어 놓기 · 붙여넣기로 넣을 수 있다. HTML 은 안에 든 원본 데이터(`<script id="oremas-log">`)로 초상 · 주사위 · 배틀 카드를 그대로 살리고, 그 데이터가 없는 옛 파일은 말풍선 꼴을 읽는다. TXT 는 날짜를 떼고 원래 파서로 읽는다.
- 오레마스에서 올린 그림은 「[그림]」 대신 그 자리에 그림으로 보이고, HTML 복사에도 들어간다.
- 읽기 전용. 오레마스와 같은 Supabase 프로젝트의 공개 키로 `om_rooms` · `om_state` · `om_log` 를 읽는다.

## 보기 설정
「보기 설정」 칸에서 테마(시스템 · 밝게 · 어둡게 · 종이 · 밤) · 본문 글꼴 · 제목/이름 글꼴 · 글씨 크기 · 줄 간격 · 초상 크기 · 초상 모양(토큰 그대로 · 둥글게 · 네모)을 고른다. 이 브라우저(`localStorage om-view`)에 기억되고, `#logcss` 에 덧붙여 「HTML 복사」로 내보낸 파일에도 그대로 들어간다(고른 글꼴은 `@import`).

## 원본 보정 (oremas-addon.html 뒷부분)
`src/original.html` 은 그대로 두고, 합친 페이지에서 원본 함수를 덮어써 고친다.
- 화자 판별: 「10:30」 같은 시각의 콜론은 이름 구분으로 읽지 않는다. 표 형식은 이름 칸에서 화자를 찾으면 본문 앞 「…:」 를 자르지 않는다.
- 주사위: `title` 이 있는 span 은 주사위처럼 보일 때(1d20 · « » · = · Rolled …)만 주사위 칩. 그냥 툴팁은 글자로 둔다.
- 그림: 본문 속 그림(http(s) · data:image)을 「[그림]」 으로 살린다. 초상은 표의 본문 칸 밖 첫 그림(또는 글자보다 앞의 첫 그림)만. 편집해도 그림이 URL 글자로 바뀌지 않는다.
- 정리기가 내보낸 HTML 을 다시 넣으면 메시지 · 화자 · 초상을 되살린다.
- 형식 판별은 진짜 태그가 있을 때만 HTML. 파일 인코딩은 UTF-8 → 문서 charset → CP949(EUC-KR) 순으로 알아본다.
- 등장인물 칸 · 출연진 칩의 초상은 지금 보는 로그의 그림이 먼저다(다른 방의 같은 이름 그림으로 바뀌지 않는다). 오레마스 초상은 전역 이름 표에 넣지 않는다.
- 예시 모드에서 생긴 화자 설정은 로그를 넣을 때 지운다. 보던 로그 선택 · 오레마스 패널 옵션을 기억한다.
- **되돌리기**(편집 칸 · Ctrl+Z, 20번까지): 줄 지우기 · 고치기 · 모두 바꾸기 · 로그 삭제 · 오레마스 새로 고침.
- 찾아 바꾸기는 지금 보이는 메시지만, 링크 글자도 바꾼다(주사위 결과는 안 바꾸고, 이름은 「등장인물」 칸에서).
- **저장 공간** 칸: 안 쓰는 그림 · 음악 지우기 / 모두 지우기(두 번 누르기).
- 「HTML 복사」 때 올린 그림(원격 주소)을 파일 안에 담는다(못 받으면 원래 주소).
- 캠페인 해제 도구 JSZip 을 cdnjs 에서 못 부르면 `vendor/jszip.min.js` 를 쓴다.
- `?oremas=` 자동 불러오기는 저장소 부팅이 끝난 뒤에 돈다. 10만 줄 넘는 방도 50만 줄까지 읽고, 넘으면 알려 준다.

## 파일
- `src/original.html` — 정리기 원본(그대로 둔다)
- `oremas-addon.html` — 오레마스 연동 덧붙임(패널 + 스크립트)
- `build.py` — 두 파일을 합쳐 `index.html` 을 만든다. 원본이 바뀌면 `src/original.html` 만 갈아 끼우고 `python build.py`.
  합치면서 `<html lang="ko">` 를 붙이고, `<body>` 안에 있던 `<title>` · `<link>` · `<script src>` 를 `<head>` 로 옮긴다.
- `vendor/jszip.min.js` — JSZip 3.10.1 (MIT/GPLv3). cdnjs 를 못 쓸 때 대신 쓴다.
- `index.html` — GitHub Pages 가 내보내는 페이지
